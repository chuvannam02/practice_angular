TÌNH HUỐNG 06 · LAZY CHUNK THẬT

Chỉ tải component báo cáo khi bấm nút

Mở DevTools → Network → lọc JS rồi bấm nút. Component standalone dưới đây nằm trong khối defer và được tải riêng nếu chưa có trong cache.

@defer (on interaction(loadReportButton)) { } @placeholder {
Chưa dựng component báo cáo. Chưa cần tải phần code riêng của nó.
} @loading (minimum 200ms) {
Đang tải chunk báo cáo…
} @error {
Không tải được chunk. Kiểm tra kết nối rồi tải lại trang.
}

Hash trong tên file phục vụ cache; namedChunks: false không tự làm ứng dụng nhẹ hơn. Thư viện đã dùng ở màn hình khác có thể nằm trong chunk dùng chung.
